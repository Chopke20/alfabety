# Alfabetkowo

Nauka polskiego alfabetu dla dzieci. 32 literki, od A do Ż, na całym ekranie.

Otwórz na tablecie:

**https://chopke20.github.io/alfabety/**

## Zabawy

- **Słuchaj** — dotknij literki, a usłyszysz jej nazwę i słowo (A jak arbuz).
- **Odkryj** — puste miejsca. Dotknięcie odkrywa literkę.
- **Powiedz** — Sówka mówi literkę, dziecko ją powtarza. Dobrze powiedziana wskakuje na planszę.
- **Zgadnij** — Sówka pyta, a dziecko wybiera jedną z czterech dużych literek.

Gwiazdki zostają na urządzeniu. Nie ma konta ani reklam.

## Ekran główny tabletu

1. Otwórz link w Chrome (Android) albo Safari (iPad).
2. Android: menu → **Dodaj do ekranu głównego**.
3. iPad: **Udostępnij** → **Do ekranu początkowego**.

Tryb Powiedz prosi o mikrofon i potrzebuje internetu, bo głos rozpoznaje przeglądarka. Nagrania nie są zapisywane. Najpewniej działa w Chrome. Na iPadzie, gdy mikrofon w przeglądarce nie działa, jest przycisk z gwiazdką.
